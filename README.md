# 海淘集市 · 跨境商品上新工作台 使用说明

团队：Baseline

技术栈：React + Fastify + Prisma / SQLite

把国内供应商的中文资料，变成可以直接上架海外平台的英文商品页，并且每一句话都能指回它的证据。

## 1. 环境要求

Node.js 22.12 或更高版本。

## 2. 启动

```bash
copy .env.example .env
npm ci
npm run dev
```

- Web 界面：<http://localhost:5173>
- 接口健康检查：<http://127.0.0.1:3001/api/health>
- 演示账号：`demo@prismlaunch.local`
- 演示密码：`Demo123456`

## 3. 演示步骤

1. **商品资料 → 导入数据**：选择 `public/demo/商品参数信息表.csv`；想看图片文字核对时，在「资料文件夹（可选）」里选中 `public/demo/可选材料` 文件夹；
2. **上新任务**：点「新建任务」，再点「创建任务」，创建的同时运行推荐，在 Top 3 里点「选择 SKU」；
3. **证据与事实**：点「分析资料」生成事实卡，在「核对与报警」里处置报警——图片文字、质检报告、物流属性三列；
4. **文案工作室**：生成文案，只使用已确认事实，语言与单位跟随所选平台；
5. **审核与发布**：运行审核，模拟发布或导出 Amazon CSV。

## 4. 目录结构

```
src/        前端界面：商品资料、上新任务、证据与事实、文案工作室、审核与发布
server/     后端接口与业务服务：选品推荐、事实卡、核对、定价、文案、审核
shared/     前后端共享的领域逻辑：事实卡、单位换算、定价与核对判定
prisma/     数据模型与数据库迁移
public/     静态资源与演示数据，全部数据文件在 public/demo/
scripts/    样例数据与样张图生成、素材挂载脚本
```

## 5. 演示数据说明

| 文件 | 是什么 | 演示什么 |
| --- | --- | --- |
| `haitao-supplier-demo.xlsx`、`haitao-supplier-demo.csv` | 内置演示供货表，8 行 | 导入到推荐 Top 3 的最快路径 |
| `haitao-bag-demo.csv` | 托特包演示行 | 包类商品自己的字段与承重风险审核 |
| `商品参数信息表.csv` | 真实供应商样表，23 行 | 行级校验：缺项、重复、类目不符，以及完整上新流程 |
| `商品参数信息表.xlsx` | 同一份表的原始版本，含多款式单元格 | 配合 `npm run split:variants` 把多款式拆成一行一款 |
| `危险品运输属性样本.csv` | 物流属性申报样例，5 行 | 液体、电池、磁性、气雾、易燃、易碎与运输放行 |
| `质检报告样本.csv` | 质检报告字段样例，6 行 | 报告编号、结论、有效期，以及报告载明的容量与材质 |
| `可选材料/` | 故意做错的样张图，5 张 | 图片文字核对：图上容量、产地、颜色与事实不符时报警 |
| `hazmat-images/` | 质检报告样张，24 张 | 提交质检报告时读图，自动取报告编号、有效期与结论 |

用法：导入时先选供货表，再在「资料文件夹（可选）」里选中 `public/demo/可选材料` 或 `public/demo/hazmat-images`，文件按文件名挂到对应 SKU。

## 6. 关键设计

- **事实卡分层**：V1 是供应商基准事实，导入后不被覆盖；V2 是任务补充事实，只做叠加并标注来源；
- **核对与报警**：图片文字、质检报告、物流属性三列，正常静默，异常才报警，每次处置都留痕；
- **门禁**：只有已确认且允许写入文案的事实才能进入文案，语言与单位按所选平台生成。
