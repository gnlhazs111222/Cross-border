# B 审核示例干扰与数字依据修复

最终版本：review-qwen-v8 / review-hard-v5。没有修改既有案例标签、发布接口或数据库。

## 调查与修复

v6 诊断表明 NEW-06 / NEW-10 的响应是合法 JSON，分别由于空 suggestedFix 和超过限制的 reason 而失败。模型将对正确标题的自我纠正放进了问题列表。不能将 invalid_ai_json 一概解释为语法错误。

750ml 与 900ml 各一次原提示词/删除容量示例的对照中，原提示词的 750ml 组出现多余错误标题和空建议，删除示例后只报告防漏承诺；900ml 两组均返回可用结果。该小规模结果支持示例干扰假设，但不足以证明唯一因果关系。

修复包括：删除具体容量示例，禁止将自我纠正放入结果，限定简短且非空的理由和建议，增加不包含商品数值的属性结构示例，明确属性是待审文案而非事实依据。

服务端增加数字来源校验：理由或建议中的数字须出现在问题原句或实际引用的已授权事实值中；否则按 invalid_review_reference 失败，不提供错误建议、不授权发布。测试先验证“事实 750ml 却建议 500ml”未被拒绝的失败，再验证修复后拒绝、建议真实 750ml 正常保留。

此检查只覆盖阿拉伯数字来源，不证明比较关系、单位、文字数字或语义正确。例如错误数字已出现在问题句中时，不能单凭来源判定修改建议是否正确；未提供的新单位换算可能被拒绝。不得宣称已经实现完整的事实蕴含验证。

## 后续边界

这批案例均已用于开发或诊断，不是独立人工盲测。状态匹配不等于问题级理由全部正确。剩余引用失败和语义关系验证应单独处理；继续增加提示词示例可能改善一组而损害另一组，需要固定输入和问题级指标。网站使用新版本后，旧审核授权会因版本变化失效，需要重新审核。
