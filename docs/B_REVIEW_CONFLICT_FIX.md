# 正确标题误报与非最终理由修复

日期：2026-09-09。当前提示词 review-qwen-v9，规则 review-hard-v7。

## 已确认原因

R2-07 第二轮真实响应一边称 canvas 与 Canvas 矛盾，一边承认匹配，并把“转去看属性”的自我纠正保留在最终问题列表。原实现仅验证位置、原句及事实键存在，没有拒绝这种未形成最终结论的理由。

## 本次修改

- 提示词增加输出前逐候选检查：只对照引用的授权事实，忽略大小写差异；不能以其他文案字段为证据，把本来正确的标题改判为矛盾。输出仅保留真正冲突的字段与简短结论。
- 对显式自我纠正标记增加 invalid_review_reason 拒绝处理。
- 对单事实引用的 spec_conflict，若问题原句与被引用的事实值经 Unicode、大小写、空白规范化后完全相同，拒绝这条不成立的冲突。
- 整体返回 failed 并保持发布锁定，不丢弃错误问题后猜测其他问题有效，也不自动变成 passed。已有审核结果会因版本改变失效。

校验是有限保护，不是完整语义蕴含检查；它不覆盖所有自我纠正表达，也不能仅凭子串包含证明整个短语正确。拒绝返回 failed 不算模型正确识别风险。提示词改善与程序拒绝必须分别评价。
