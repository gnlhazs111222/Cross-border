适用 review-qwen-v13 / review-hard-v10，约 4–6 分钟，网络等待另计。本文件为操作稿，不表示文档整理时又执行了网页或模型调用。

## 准备

按 [交付说明](B_REVIEW_DEMO_HANDOFF.md) 启动并正常登录，确认“规则 + Qwen”。本机任务 B-ACCEPT-1788879026672，Shopify，SKU LM-KT-BTL-001-BLK-500。最近实测停在文案第 20 版，后续递增正常。队友机器没有本机数据库时，通过正常导入和事实确认流程准备独立演示任务。

事实前提：Black、Stainless Steel、500ml / 16.9 fl oz、Screw-top lid 已确认且允许使用，没有已确认重量依据。先记录原文，结束时恢复。不使用重置演示，也不修改事实去迎合错误文案。

基准文案：

```text
标题：Black stainless steel bottle, 500ml
卖点：Capacity: 500ml.
描述：Black stainless steel bottle with a screw-top lid.
```

保留与事实一致的属性，清除其他无依据宣称。编辑路径：“前往文案工作室编辑”→“编辑文案”→“保存新版本”→“继续前往审核”。每次保存后先展示发布不可用，再运行审核。

## 操作与讲解

| 环节 | 操作 | 预期及讲解 |
|---|---|---|
| 正常通过 | 基准文案点击“运行审核”，展开追踪 | passed；展示模型、版本、调用 ID，说明依据事实审核 |
| 修改失效 | 只把标题 500ml 改为 750ml，保存 | 当前版未批准，发布锁定；旧版通过不能批准新版 |
| 找出错误 | 运行审核 | blocked；标题 750ml、规格矛盾、capacity 引用，建议改回 500ml；正确卖点和属性不应被指控。刷新确认状态保留 |
| 修正重审 | 标题恢复 500ml，保存后展示仍需审核，再审核 | passed；修正不会自动批准，必须重审 |
| 人工复核 | 在正确描述末尾增加 `Lightweight design.`，保存并审核 | needs_human_review；没有重量依据，不能批准，也不能断言产品一定很重 |
| 恢复收尾 | 删除新增短句，恢复原正常文案，保存并审核 | passed；刷新后保留。停在正常状态即可，无需点击模拟发布 |

完整流程预计 5 次主动审核。若开始时展示已有通过记录，说明它是历史结果，不冒充新调用。审核来源和文案生成来源分别说明。

容量冲突与修正有历史网页证据；最新 v13/hard-v10 有隐含防漏网页闭环证据。模糊描述策略有第三轮 R3-16 台灯 API 案例支持，但此稿中的水杯人工复核组合尚未单独网页实测，预期不能写成实测结论。

## 可选：隐含防漏替换规格冲突

在基准描述后增加：

```text
Carry it beside your notebook; even if the bottle tips over, every page stays dry.
```

预期发现无依据防漏承诺。解释讨论杯盖时应引用 lidType；存在未授权 leakproof 时，按实际分类关联。此输入有 [最新网页实测](B_REVIEW_LOCATION_FIX.md)。不要用 `100% leakproof` 单独证明 Qwen 能力，它可能直接命中本地规则。

## 异常处理

结果不同于预期时，保留首次调用 ID、版本、错误码和问题。failed 是审核未完成，不是成功识别风险；错误放行和误报也应如实记录。不要连续重试挑成功结果。

认证或网络原因排除后若手动重试，应说明是第二次调用；时间不足时展示历史验收记录并标注版本。若收尾无法恢复通过，先恢复原文并保持发布锁定，不把恢复文案说成已恢复批准。
