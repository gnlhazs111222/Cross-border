棱镜上新｜技术路线图

处理目标核心技术项目阶段
资料库支线
资料输入、校验、去重与基础事实卡 v1

前端资料工作台

Vue 3 + TypeScript + Vite
实现 Excel／可读 PDF／图片上传、字段表单、待补提示、来源查看与重复处理界面；导入批次可保存并追溯。

文件解析与资料状态

FastAPI + Pydantic + openpyxl/pandas
解析表格／可读文档字段并关联 SKU 与图片资源；按身份字段和候选池准入字段标记 draft_blocked／needs_completion／search_ready，不以成本、重量、尺寸阻塞资料保存。

重复识别算法

SKU／条码精确匹配 + 文件哈希 + 属性相似度
完全重复仅保留导入日志；疑似重复进入人工合并审核；只有 unique + search_ready 的记录可进入候选池。

私有资料与 v1 存储

本地文件／MinIO + PostgreSQL
原始文件进入私有数据区，商品字段、来源、资料状态和去重状态写入数据库；仅 unique + search_ready 生成可检索基础事实卡 v1。

边界：资料输入可独立运行：导入批次与待补记录均可保存；draft_blocked 不建 v1，needs_completion 不入候选池，只有 search_ready + unique 才入池并建 v1。图片在此仅上传并关联 SKU；不识别图片、不执行 OCR、不做图片—资料核验。

上新任务与选品
任务条件结构化、检索召回与语义重排

受控任务表单与定价上下文快照

Vue 3 表单组件 + 后端枚举校验
固定填写目标平台、国家、中文一级类目及可选履约档案；任务创建成功时冻结汇率、费用／物流模板与税费口径版本。最低单件利润为可选售价参数，不参与任务准入。

任务条件大模型调用

百炼大语言模型 API + JSON Schema
将固定条件与补充要求整理成可审阅、可编辑的任务条件卡，拒绝覆盖固定条件。

候选查询与语义重排

PostgreSQL 结构化过滤 + 关键词匹配 + qwen3-rerank
MVP 先硬筛选候选池，再将候选摘要送入重排；Elasticsearch、向量库与 RRF 仅作为规模化后的扩展。

重排与规则结论

qwen3-rerank API + 规则引擎
重排只调整合格候选的相关性顺序；规则引擎依据硬条件、资料状态、去重与风险给出推荐／备选／不推荐结论，模型仅解释理由。

边界：智能选品只读候选商品池中的 v1，且仅接收 search_ready + unique 记录；任务创建时冻结的定价上下文不含 SKU 特定成本或物流事实，最低单件利润、汇率、税费和建议售价均不参与召回、重排或推荐排序。

多模态事实确认
多模态解析、证据回写与增强事实卡 v2

异步解析编排

FastAPI + 数据库任务状态 + 后台任务
运营人员选中 SKU 后创建任务级解析任务，记录处理状态、重试次数与任务日志；Celery + Redis 为后期并发与重试增强。

多模态模型调用

千问多模态模型 API／本地模型
仅向云端发送当前选中 SKU 所需的图片、裁剪区域或 PDF 页面以执行图片理解、OCR 与视觉信息提取；敏感资料留在本地或转人工。

图片—资料核验

结构化字段比对 + 置信规则
比对可见颜色、容量、配件、包装文字与 v1；输出证据位置、置信状态和可用图片资源。

事实卡版本合并

PostgreSQL 版本表 + 证据索引
以 v1 为底稿，为“任务 + SKU”创建多模态增强事实卡 v2，并保留证据；v2 不覆盖或改写 v1，供后续模块只读使用。

边界：多模态解析是唯一负责图片识别、OCR 与图片—资料核验的模块；模型只能输出待审核候选，商品事实卡服务只保存、版本化合并和输出结果，不给可发布结论。

售价与 Listing
任务级价格快照、建议售价反算与受控内容生成

创建时冻结的定价上下文

版本化费用配置 + 明确汇率数据源
任务创建时按平台、国家与履约档案冻结参考汇率、费用／物流模板与税费口径；SKU 的 v2 事实仅在后续可选测算时读取，MCP 仅可作为调用接口。

建议售价计算服务

Python Decimal + 可配置公式引擎
可选增强模块：以创建时冻结的任务级定价上下文叠加 SKU v2 事实，按换汇成本、物流、关税预估、平台费用和可选最低单件利润反算建议售价，并保留测算版本。

规则与术语检索增强

RAG + 来源引用
RAG 仅检索平台规则、本地化术语和写作模板；当前 SKU 的已确认事实由 SKU + v2 版本 + 平台 直接读取。

受控 Listing 生成

百炼大语言模型 API + JSON Schema
生成 Amazon US/Shopify US 草稿、单位换算和字段映射；每个字段保留事实来源。

边界：售价计算为可选增强模块，不能阻塞 Listing 审核；任务级定价上下文已在创建任务时冻结，v2 与计算资料齐备后才按需读取，可由运营人员修改并留痕，不影响选品结果，也不自动写入标题、卖点和详情页文案。平台、国家、履约档案变更或明确重定价必须新建快照版本。

审核、发布与反馈
规则审核、官方授权发布与可追溯反馈

Listing 审核工作台

Vue 3 差异对比界面 + 字段级修订
展示文案、事实来源、风险提示、审核意见与版本差异，高风险未关闭时禁用发布。

平台规则与风险引擎

规则 DSL + 关键词／字段校验
筛查第三方品牌词、可疑 Logo、授权材料缺失、敏感内容与平台字段问题，并提示人工复核；系统不自动给出法律结论。

平台授权与连接器

Shopify OAuth 2.0 + 最小权限访问令牌
经平台官方授权调用 Shopify Admin API；Amazon 首期导出可复核上传文件，不保存平台账户密码。

发布反馈与审计

FastAPI 连接器 + PostgreSQL 日志
保存请求、响应、错误码、审核版本、v2 版本与售价版本；失败任务回流到草稿修订。

安全边界：仅使用平台官方授权与最小权限访问令牌；系统不收集、不明文保存账户密码，不绕过平台认证、验证码、二次验证或权限校验。

贯穿支撑层
前端、后端、数据与部署基础设施

前端

Vue 3 + TypeScript + Vite
资料工作台、任务表单、事实卡、价格、Listing、审核与发布页面。

后端与任务编排

FastAPI + Pydantic + 数据库任务状态
REST API、结构化校验、异步多模态解析、价格任务与发布任务；Celery + Redis 作为后期增强。

数据与检索

PostgreSQL + 本地文件／MinIO
保存事实卡版本、文件证据、候选摘要与审计日志；pgvector、RRF 与独立搜索集群作为后期扩展。

部署与安全

Docker Compose + Nginx + HTTPS
服务容器化、反向代理、访问控制、密钥管理与最小权限审计。

总体技术原则：原始 Excel、图片、PDF 和完整商品目录保留在私有数据区。云端文本模型仅接收当前任务所需的条件、候选摘要、已确认事实与规则片段；云端多模态模型仅接收当前选中 SKU 的最小必要图片、裁剪区域或文档页面，并记录传输范围与调用日志，敏感资料留在本地或转人工。模型输出先通过 JSON Schema 校验，再交由规则引擎和人工审核处理；模型不修改商品主数据、不清除导入告警、不让重复商品入库，也不能绕过审核直接发布。
