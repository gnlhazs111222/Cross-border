# 单文本字段零索引兼容修复

2026-09-09；review-qwen-v13 / review-hard-v10。基线 926007a。

## 原因

固定第 17 版输入重现了网页的 invalid_review_location：模型对 description 返回了 index: 0。其问题原句、理由、lidType 和 leakproof 引用均有效；但描述是单个字符串，原校验要求没有 index，导致整个结果失败。诊断捕获是相同输入哈希的后续调用，不是原始网页响应原件。

## 修复范围

仅在 title 或 description 的 index 为数字 0 时删除这个冗余索引。非零索引、字符串索引、属性索引仍被拒绝。卖点必需的索引、属性必需的 key、字段与原句匹配、引用及发布授权校验保持有效。不会改写或猜测问题原句，也不会从其他字段搜索替代位置。提示词未改，规则升至 v10 使旧审核授权失效。

- 新增测试在旧实现先失败；修复后捕获响应重放及边界条件通过。
- 全量 114 项服务端测试通过，类型检查通过。
- 同一输入修复后真实调用仍返回 description/index:0，现在正确得到 blocked，原句及 lidType、leakproof 引用保留。

- 恢复原正常描述为第 20 版，保存后仍需审核；真实审核通过，刷新后通过状态和可用的发布按钮保留。未点击发布，未修改事实卡。
