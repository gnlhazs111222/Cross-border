PRISMLAUNCH · SYSTEM ARCHITECTURE

棱镜上新｜系统架构图

本图按当前仓库的实际实现绘制：React 19 + Vite 工作台 → Fastify API → 领域服务 → 可切换 Provider → 阿里云百炼模型 / 本地离线实现 → Prisma + SQLite。默认全部离线可跑，模型能力需显式开启。

前端与接口 服务与实现 模型调用 数据与安全
使用角色
谁在用：运营、主管与供应链

运营

导入商品资料、核对事实、处理报警、生成与修改文案、提交审核。

主管

提出上新需求、确认选品结果、审核文案版本并决定是否导出。

供应链 / 品控

在同一任务内提供物流属性与报价，提交质检报告，供后续核对与定价使用。

前端工作台
React 19 + TypeScript + Vite 7 + Tailwind CSS 4

商品资料

供应商表格与素材导入、导入预览与行级校验、商品详情与字段补齐。

上新任务

平台 / 国家 / 类目选择、一句话需求、选品条件卡编辑与推荐结果。

证据与事实

事实卡编辑与确认、核对与报警面板、质检报告、定价快照。

文案工作室

Amazon / Shopify 文案生成、事实来源与版本展开、字段级修改。

审核与发布

规则 + 语义审核结果、修订与重审、导出 Amazon 上传文件。

组件库：Radix UI（对话框、标签页）+ lucide-react 图标 + 自建 i18n（zh.json）。另有独立离线比赛版：npm run dev:local（5174 端口，无需登录与后端）。

后端接口层
Fastify 5 REST API + Zod 校验 + Cookie 会话

认证与权限

登录 / 注册 / 登出、Cookie 会话、受保护路由、演示数据重置。

统一校验与错误

请求体、参数与查询的 Zod 模式校验；统一错误码与错误处理。

文件与资产接口

素材上传与读取、远程图片白名单抓取、体积与数量上限控制。

能力查询接口

/api/capabilities 返回当前实际生效的 Provider 与模型，前端据此提示"当前是离线还是真实模型"。

端口：API 默认 127.0.0.1:3001，Web 默认 localhost:5173；npm run dev 会先自动执行数据库迁移与种子数据，再并行启动两端。

领域服务
业务规则写在服务层，模型不直接改数据

导入与对齐
imports / alignment

表格与素材解析后的行级校验、重复与冲突识别、合并规则（ImportResolutionRule）与批量处置。

目录与事实
catalog / facts

商品池与事实卡（v1 / v2）读写、字段取值与来源（Evidence）、人工确认与修订版本管理。

核对与报警
checks / hazmat / quality report

图片文字、质检报告、物流属性三类核对；正常静默、异常报警，处置结果带乐观锁写入并留痕。

定价快照
pricing-snapshots

创建任务时冻结汇率、运费配置、关税与平台费口径；刷新生成新版本并使历史发布结果失效。

选品推荐
recommendations

按任务条件硬筛选候选，再由规则结论或模型理由排序；模型只能调整顺序，不能放行不合格候选。

文案与审核
listings

模板或模型生成 Amazon / Shopify 文案，结构校验与事实授权校验；审核为"本地硬规则 + 语义复核"两级。

多模态核对
multimodal

读取商品图片中的印字，与事实卡比对，输出差异与置信状态；默认离线只做文件级核对。

失效与版本
invalidation

事实、任务或文案任一版本变化，相关下游结果标记失效，避免用旧事实发布。

Provider 层
四类能力可独立切换，默认全部离线

推荐 Provider

rule（默认） / qwen
Qwen 失败自动回退规则结论。

文案 Provider

template（默认） / qwen
Qwen 失败自动回退模板。

审核 Provider

rules（默认） / qwen
先跑本地硬规则，再复核模型结果；失败或歧义不会回退成通过。

多模态 Provider

local（默认） / qwen
离线只做文件级核对、属性标未核对。

接口：统一抽象为 TextModelProvider（generateText / generateStructured），Mock 与 Bailian 两套实现；调用带输入哈希缓存，模型输出先过 JSON Schema 与字段授权校验，再进入业务版本链。

模型调用
阿里云百炼（OpenAI 兼容模式）

文本生成

qwen3.6-flash
文案生成、语义审核、推荐理由。

推理

qwen3.7-plus
需要更强推理的复核场景。

视觉多模态

qwen3.7-plus
图片印字识别与质检报告读取。

高阶模型

qwen3.8-max
默认关闭（AI_ALLOW_PREMIUM=false），需显式授权。

调用约束：官方 OpenAI JS SDK 指向用户提供的兼容基地址；单次请求 30 秒超时、不自动重试；默认 AI_LIVE_ENABLED=false，每个 API 进程最多 20 次真实调用；只记录 provider、模型、耗时、是否成功与 token 用量，不记录完整提示词与凭据。

数据与资产
Prisma 6 + SQLite（本地文件库，权威数据源）

账号与导入

User、Session、Product、ProductAsset、ImportBatch、ImportOccurrence、ImportResolutionRule。

任务与定价

LaunchTask、TaskSelection、PricingSnapshot。

事实与产出

FactCard、Fact、Evidence、ListingDraft、ReviewResult、PublishResult。

调用与资产

AiCall（调用元数据）；素材文件存于 .local/assets，单文件上限 4 MB、每商品上限 20 个。

数据边界：业务状态以 SQLite 为权威来源，浏览器只保留界面偏好与非权威快照；清空 localStorage 后仍可从数据库恢复任务、事实、审核与发布结果。

贯穿全局的安全与质量约束：① 百炼 API Key 只存在于服务端 .env，不进入前端构建产物，构建前可执行 npm run security:check 扫描；② 所有模型输出先经结构化校验与"事实授权"校验，只有已确认、允许公开的事实才能进入文案；③ 事实、任务、文案均带版本号，写操作使用乐观锁（expectedRevision），任一层变化都会让下游结果失效；④ 测试与自检命令为 npm run typecheck、npm run test:server、npm run test:e2e、npx vite build，测试进程强制关闭真实模型调用并清空 Key；⑤ 当前不接入任何平台店铺 API，Amazon 上传文件与 Shopify 草稿内容均在本地生成。
