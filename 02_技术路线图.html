棱镜上新｜技术路线图

处理目标核心技术项目阶段
资料库支线
资料输入、校验、去重与基础事实卡 v1

前端资料工作台

Vue 3 + TypeScript + Vite
实现 Excel/PDF/图片上传、字段表单、红色必填提示、来源查看和重复处理界面。

文件解析与字段校验

FastAPI + Pydantic + openpyxl/pandas
解析表格并建立 SKU 关联；以 Schema 校验名称、类目、成本、重量、尺寸等保存必填项。

重复识别算法

SKU/条码精确匹配 + 文件哈希 + 属性相似度
完全重复直接拦截；疑似重复进入人工合并审核，不进入候选池。

私有资料与 v1 存储

MinIO 对象存储 + PostgreSQL
原始文件进入对象存储，商品字段、来源、版本、重复状态写入数据库，生成基础事实卡 v1。

边界：资料输入可独立运行。图片在这里仅上传并关联 SKU；不识别图片、不执行 OCR、不做图片—资料核验。

上新任务与选品
任务条件结构化、检索召回与语义重排

受控任务表单

Vue 3 表单组件 + 后端枚举校验
固定填写目标平台、国家、中文一级类目、最低单件利润；自然语言只补充偏好与排除项。

任务条件大模型调用

百炼大语言模型 API + JSON Schema
将固定条件与补充要求整理成可审阅、可编辑的任务条件卡，拒绝覆盖固定条件。

混合检索与结果融合

Elasticsearch BM25 + BGE-M3 向量检索 + Milvus
关键词与语义双路召回候选商品，采用 RRF 融合结果。

重排与规则过滤

qwen3-rerank API + 规则引擎
对 Top-N 按条件卡进行语义重排，再排除完全重复、疑似重复待合并商品并输出推荐理由。

边界：智能选品只读候选商品池中的 v1；最低单件利润、汇率、税费和建议售价均不参与召回、重排或推荐排序。

多模态事实确认
多模态解析、证据回写与增强事实卡 v2

异步解析编排

FastAPI + Celery + Redis
运营人员选中 SKU 后创建异步解析任务，记录处理状态、重试次数与任务日志。

多模态模型调用

千问多模态模型 API
对商品图、包装图、规格 PDF 执行图片理解、OCR 与视觉信息提取；私有化时可切换附件九中的本地模型。

图片—资料核验

结构化字段比对 + 置信规则
比对可见颜色、容量、配件、包装文字与 v1；输出证据位置、置信状态和可用图片资源。

事实卡版本合并

PostgreSQL 版本表 + 证据索引
将解析结果写回事实卡服务，由 v1 生成多模态增强事实卡 v2，供后续模块只读使用。

边界：多模态解析是唯一负责图片识别、OCR 与图片—资料核验的模块；商品事实卡服务只保存、版本化合并和输出结果。

售价与 Listing
任务级价格快照、建议售价反算与受控内容生成

汇率、费率与税费快照

MCP 工具网关 / 官方数据 API + 配置中心
每个新任务获取参考汇率并冻结；平台费率、物流模板和税费口径按版本读取。

建议售价计算服务

Python Decimal + 可配置公式引擎
按换汇成本、物流、关税预估、平台费用和最低单件利润反算建议售价，并保留测算版本。

私有资料检索增强

RAG + 向量库 + 来源引用
从 v2、平台规则和本地化术语资料中检索本次生成所需的已确认事实与规则片段。

受控 Listing 生成

百炼大语言模型 API + JSON Schema
生成 Amazon US/Shopify US 草稿、单位换算和字段映射；每个字段保留事实来源。

边界：建议售价在 v2 后、Listing 前计算，可由运营人员修改并留痕；它不影响选品结果，也不自动写入标题、卖点和详情页文案。

审核、发布与反馈
规则审核、官方授权发布与可追溯反馈

Listing 审核工作台

Vue 3 差异对比界面 + 字段级修订
展示文案、事实来源、风险提示、审核意见与版本差异，高风险未关闭时禁用发布。

平台规则与风险引擎

规则 DSL + 关键词/字段校验
检查平台字段、变体、风险词、品牌/知识产权与商家授权；不重新识别图片或核对资料。

免密授权与平台连接器

OAuth 2.0 / SSO / 官方授权令牌
使用已有安全登录态和最小权限令牌调用 Shopify Admin API；Amazon 首期导出可复核上传文件。

发布反馈与审计

FastAPI 连接器 + PostgreSQL 日志
保存请求、响应、错误码、审核版本、v2 版本与售价版本；失败任务回流到草稿修订。

安全边界：免密登录仅使用 OAuth、SSO 或官方授权令牌；系统不收集、不明文保存账户密码，不绕过平台认证、验证码、二次验证或权限校验。

贯穿支撑层
前端、后端、数据与部署基础设施

前端

Vue 3 + TypeScript + Vite
资料工作台、任务表单、事实卡、价格、Listing、审核与发布页面。

后端与任务编排

FastAPI + Pydantic + Celery + Redis
REST API、结构化校验、异步多模态解析、价格任务与发布任务。

数据与检索

PostgreSQL + MinIO + Elasticsearch + Milvus
事实卡版本、文件证据、BM25 召回、向量索引与审计日志。

部署与安全

Docker Compose + Nginx + HTTPS
服务容器化、反向代理、访问控制、密钥管理与最小权限审计。

总体技术原则：原始 Excel、图片、PDF 和完整商品目录保留在私有数据区；云端模型仅接收当前任务所需的条件、候选摘要、已确认事实与规则片段。模型输出先通过 JSON Schema 校验，再交由规则引擎和人工审核处理；模型不修改商品主数据、不清除导入告警、不让重复商品入库，也不能绕过审核直接发布。
